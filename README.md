# WEATHER HEALTH DB
 #### Video Demo: <URL>
 #### Description: This is step one in a larger research project on environmental determinents of respiratory health. This database pipes in open source data from NCEI and OpenAQ APIs. The data that is extracted is weather (Humidity, Precipitaiton, and Temperature) and Air Quality (Co, O3, No, No2, Nox, So2, PM25, and Pm10).
 In the future, there will be a personal app that will interface with this DB for patients with asthma to record their personal biomarkers and history of asthma attacks. All three categories of data will then pipe to a machine learning algorithm that will be able to predict respiratory events for that particular patient given the types of weather and air quality parameters that are forcasted.

To run the ETL pipeline and build the db yourself, download this repo and run the exe.py script.
